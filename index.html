Agent tutorials work, until production

Most tutorials run the whole agent loop in one long request. That dies on timeouts, loses everything on a crash, and can't be observed mid-run. This kit decomposes the loop into single short iterations, each persisted to Postgres.

enqueue→ queue→ claim → iterate (<25s) → checkpoint× N → complete

Any worker can run any iteration. A crash costs one step, never the run.
